# Video Production Guide for FindMyPuppy

## Quick Start Options

### Option 1: Screen Recording (Easiest)
1. **Record Gameplay:**
   - Use OBS Studio (free) or QuickTime (Mac)
   - Record at 1080p, 30fps minimum
   - Record actual gameplay following the script

2. **Edit:**
   - Use CapCut (free, mobile/desktop)
   - Add text overlays, arrows, highlights
   - Add background music
   - Add voiceover or text-to-speech

3. **Export:**
   - 1080p, MP4 format
   - Optimize for web (under 50MB if possible)

### Option 2: Professional Tools
- **Adobe Premiere Pro** - Full editing suite
- **Final Cut Pro** (Mac) - Professional editing
- **DaVinci Resolve** - Free professional tool

### Option 3: AI-Generated Video
- **Synthesia** - AI avatars with script
- **D-ID** - Talking avatars
- **Runway ML** - AI video generation

### Option 4: Animated Tutorial
- Create animated GIFs for each step
- Use tools like ScreenToGif or LICEcap
- Embed in app as interactive guide

## Step-by-Step Recording Checklist

### Pre-Production:
- [ ] Prepare game account with different difficulty levels unlocked
- [ ] Test all features to ensure smooth recording
- [ ] Write/record voiceover script
- [ ] Choose background music (royalty-free)
- [ ] Prepare graphics/overlays (arrows, highlights)

### Recording:
- [ ] Record intro sequence
- [ ] Record difficulty selection
- [ ] Record gameplay for each difficulty
- [ ] Record hint usage
- [ ] Record wrong attempts demonstration
- [ ] Record level completion
- [ ] Record multiple puppy finds
- [ ] Record zoom/pan demonstrations

### Post-Production:
- [ ] Edit clips together
- [ ] Add text overlays
- [ ] Add arrows/indicators
- [ ] Add background music
- [ ] Add voiceover
- [ ] Add transitions
- [ ] Color correction
- [ ] Export final video

## Recommended Video Specifications

- **Resolution:** 1920x1080 (1080p) or 1280x720 (720p)
- **Frame Rate:** 30fps
- **Format:** MP4 (H.264)
- **Duration:** 2-3 minutes
- **File Size:** Under 50MB for web
- **Aspect Ratio:** 16:9 (landscape) or 9:16 (vertical for mobile)
